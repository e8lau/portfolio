description: >-
  Building on the approved reorganization proposal, I led the development and deployment of the Woodside High School
  Student Government webpage. Using custom HTML and jQuery scripts, I implemented an embedded-document system allowing
  Board of Student Affairs (BOSA) members to edit live content directly through Google Drive without CMS credentials.
  The project introduced a dynamic tabbed layout for officer bios, a Leadership Public Folder for archival transparency,
  and a script-based fix for hyperlink security errors within iframes. Upon launch, the webpage became the central hub
  for student-government communication, enabling secure, real-time updates by authorized representatives and setting a
  precedent for digital accessibility across district-hosted school sites.
